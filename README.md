# Flutter Firebase App

Aplicación móvil desarrollada utilizando Flutter para el frontend y Firebase como plataforma para el almacenamiento y gestión de datos en la nube.

## Tecnologías utilizadas

* Flutter
* Dart
* Firebase
* Cloud Firestore
* Firebase Authentication

## Descripción

El proyecto consiste en una aplicación móvil que utiliza Firebase para almacenar y gestionar información en tiempo real, permitiendo la sincronización de datos entre la aplicación y la nube.

La aplicación fue desarrollada con Flutter, aprovechando los servicios de Firebase para simplificar la gestión de datos y la comunicación con el backend.

## Funcionalidades

* Almacenamiento de información en la nube
* Consulta y actualización de datos
* Integración con Firebase
* Sincronización en tiempo real
* Interfaz móvil multiplataforma

## Lo que aprendí

Durante este proyecto aprendí a:

* Integrar Firebase en aplicaciones Flutter
* Utilizar Cloud Firestore para almacenar datos
* Gestionar información en tiempo real
* Estructurar proyectos móviles conectados a servicios en la nube
* Trabajar con bases de datos NoSQL

## Proyecto académico

Este proyecto fue desarrollado como parte de la materia de Programación Avanzada de Apps de la Universidad San Francisco de Quito (USFQ).
